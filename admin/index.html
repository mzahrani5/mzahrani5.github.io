تفعيل التغييرات على الموقع

اربط الصفحة بحسابك في GitHub (مرة واحدة)
  1. افتح صفحة إنشاء مفتاح GitHub وسجّل الدخول.
  2. اختر مدة «No expiration» وتأكد أن خيار gist محدد، ثم اضغط Generate token.
  3. انسخ المفتاح (يبدأ بـ ghp_) والصقه هنا.

يُحفظ المفتاح في هذا المتصفح فقط، ويُستخدم لتحديث ملف الرموز في موقعك.

الرمز الجديد يعمل فور التفعيل. والرمز الملغى أو المنتهي يتوقف عند أول فتح للسجل بعد التفعيل، بشرط أن يكون جهاز المشترك متصلاً بالإنترنت.
